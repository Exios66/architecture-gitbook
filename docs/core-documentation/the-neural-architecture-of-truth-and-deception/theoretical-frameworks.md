# Theoretical Frameworks

### Fuzzy-Trace Theory

The Fuzzy-trace theory (FTT) provides insight into how AI-induced false memories form. According to FTT, we encode and store two distinct types of memory traces:

* **Verbatim traces**: Represent the surface form or exact details of an event
* **Gist traces**: Preserve the semantic features or general meaning of an event
  * False memories are more likely to form when individuals rely heavily on gist traces in the absence of accurate verbatim information[8](https://pmc.ncbi.nlm.nih.gov/articles/PMC10567586/). AI systems that provide information aligned with the gist of an event but contain inaccurate details can exploit this vulnerability in human memory.
